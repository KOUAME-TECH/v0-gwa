# Frontend UI — `components`

UI uniquement. Pas de secrets. Les mutations passent par `app/api/*`.

| Dossier | Rôle |
|---------|------|
| `brand/` | Logo / marque (`GwaMark`) |
| `ui/` | Primitives (boutons, inputs…) |
| `auth/` | Formulaires téléphone / OTP |
| `chat/` | Messagerie |
| `orders/` | Escrow, litige |
| `cart/` | Badge panier |
| `yelly/` | Aide in-app |
| `pwa/` | OneSignal, service worker |
| `layout/` | Shell app |
| `feed/` · `media/` · `comments/` | Social / médias |

Pages = `app/**/page.tsx` (composition). Hooks = `hooks/`.
