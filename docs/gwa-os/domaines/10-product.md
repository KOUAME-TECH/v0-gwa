## État actuel

- **Promesse :** marketplace agri CI + confiance (escrow applicatif, SCG), PWA.
- **Personas :** producteur · acheteur · coopérative · admin (souvent dual-identity).
- **Canal principal jusqu’au 1er sept 2026 :** PWA web (pas store natif).
- **Soft-launch :** invite-only recommandé (ex. SIDONOBIEL) tant que FeexPay E2E non vert.

## Règles établies

1. **Scope agri** — hors formations / learning / artisans génériques (voir `scope-beta.md`).
2. **Type de compte verrouillé** après inscription (pas de self-service change).
3. **Acheteur retail = free forever** pour acheter ; monétisation côté offre.
4. **Hero / UX brand** : règles design repo (éviter layouts génériques AI) ; Acc-1 a11y livré.
5. **Shell unique** : bottom nav + top nav ; pas de double chrome (wallet/affacturage corrigés ; coop encore hors shell).
